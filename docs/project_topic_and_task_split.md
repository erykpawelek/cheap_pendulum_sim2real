## Project Topic and Task Split

**Topic (Theme 5.1):** Optimizing an RL pendulum-balancing policy for memory footprint. An RL agent learns to balance a pendulum in a digital twin. An optimization framework then searches for the best trade-off between balancing performance and memory footprint, with the full agent as the baseline.
